Mac에서 로컬로 실행

어떤 AI 서비스를 지원하나요?

Codex, Cursor, Claude Code, Antigravity를 통한 Gemini 한도, Claude API 조직 보고를 지원합니다. OpenRouter, DeepSeek, Kimi, Z.ai, Venice는 계정에 따라 잔액, 지출 또는 한도를 표시합니다.

QuotaAI 계정을 만들어야 하나요?

QuotaAI는 Mac에서 로컬로 실행됩니다. 사용하는 서비스에 로그인하고, API 키가 필요한 서비스는 설정에서 키를 추가하세요.
