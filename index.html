Frequently asked questions

Which AI services can I track?

QuotaAI supports Codex, Cursor, Claude Code, Gemini quota through Antigravity, and eligible Claude API reporting. OpenRouter, DeepSeek, Kimi, Z.ai, and Venice provide balances, costs, or quotas depending on the account.

Do I need to create a QuotaAI account?

No. QuotaAI runs locally. Sign in to the providers you use, or add a supported API key in Settings when the provider requires one.

Is QuotaAI available for Windows?

Yes. The Windows x64 preview is available as a standalone executable.
